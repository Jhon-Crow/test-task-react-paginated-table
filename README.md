# Задание
Для примера возьмем API https://mockapi.io/  там нужно создать список пользователей чтоб потом делать запросы на создание получение и редактирование .
### Необходимо сделать 2 страницы:
- Первая страница: список пользователей c отображение информации о них в таблице с пагинацией. Тут же сделать кнопку по нажатию на которое откроется модальное окно для создания и редактирования пользователя с формой.
- На второй странице при нажатии на пользователя открывается более детальная информация.
Шаблон проекта должен быть React
#### Использовать JS-библиотеки все кроме React и TS опционально:
React + TypeScript  
axios — для работы с API  
react-router-dom — для навигации  
redux + redux-toolkit + redux-thunk  
redux-persist — по желанию (как плюс)  
UI — можно использовать стандартные компоненты или Material UI (если хочешь чуть удобнее)  
Обработка ошибок —  отображение в UI  

Предоставить ссылку на github и сделать деплой на любой бесплатный сервис.
